Credits

Fonts, icons, and outside tools used to build this site.

Fonts

All typefaces via Google Fonts: IM Fell English, EB Garamond, Courier Prime, and Caveat.

Icons

Calendar holiday icons — Lucide, ISC License, Tabler Icons, MIT License, and Hugeicons via Iconify, MIT License.
The house stamp on the Guestbook's drawing canvas was shaped after a Material-style home icon referenced from icons8 (redrawn from scratch as a canvas shape, not a used asset).
The token icon in Crossroads is from Material Design Icons by Pictogrammers, Apache License 2.0.

Photos

Real-world reference photos (the theater curtains, desk paper textures, the pen, and similar) sourced from Unsplash, Pixabay, and Pexels.
The desk's rolling die faces are from a playing dice 3D vector set via Magnific/Freepik.
